This is the home page for my Computer Science capstone. The three artifacts below are the ones I plan to enhance: a reverse-engineered client program, a contact list, and a warehouse inventory app.

Software engineering and design

SNHU Investments client program, from CS-410. Five clients are stored in parallel variables. The planned enhancement replaces those variables with one client type and removes the plaintext password and the buffer overflow.

Algorithms and data structures

Contact Service, from CS-320. A hash map finds a contact by ID. The planned enhancement adds a tree keyed by last name so a sorted listing does not scan the map.

Databases

InventoryApp, from CS-360. Warehouse stock is stored on the phone. The planned enhancement moves that stock to a shared MySQL database, with a transaction around each quantity change.
